## Scripts

```bash
 pn tw
```

> pn (pnpm) will run `tw` script which will build your CSS and watch it.

| Input file  | Output file  | Both Files Located At |
| :---------- | :----------- | :-------------------- |
| `input.css` | `output.css` | `/assets/styles`      |

## Notes

> We have a `gitCommands.js` file in `constants` folder which has git commands datas.

> In `main.js` file we render codes based on `gitCommands.js` datas.
